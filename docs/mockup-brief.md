# 목업 브리프

## 목적

본구현 전에 정적 HTML로 **화면·정보 계층·페이지 분리**를 합의한다.  
기능 기준: `docs/기능분석.md`

## 확정 IA (엑셀 시트 1:1)

| 페이지 | 파일 | 한 가지 목적 |
|--------|------|--------------|
| 달력 | `mockups/calendar.html` | 연/월/시작일 조작 + 월간 그리드 투영 |
| 할일 | `mockups/todos.html` | 대시보드(KPI·필터·차트) + 할일표 + Note/Check List |
| 만다라트 | `mockups/mandalart.html` | 9×9 목표 보드 |
| 설정 | `mockups/settings.html` | 구분 ↔ 아이콘 |

공통 상단 네비: `달력 | 할일 | 만다라트 | 설정`

## 검증 포인트

1. 달력 우측: 연도 스피너 · 1–12월 · 시작일
2. 일차 셀: 아이콘 · 표시 · 제목 · 진행률
3. 할일 상단 KPI/슬라이서 배치와 표 밀도
4. 진행률 바 UI
5. 만다라트 9×9 역할(핵심/세부/실행)
6. 세팅 예시(일정🗓️ 할일✔️ 회의🎬)

## 비범위 (목업)

- 실제 저장/CRUD, React, 배포
- 엑셀 단축키·피벗 UI 복제
