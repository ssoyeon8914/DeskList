# 엑셀 기능 재분석 (이미지 기준)

기준: `docs/To_do_list_2.2.xlsx` + 사용자 첨부 화면 캡처 4장  
시트: `달력` · `할일` · `만다라트` · `세팅` (+ 숨김 `피벗`, `설명서`)

---

## 0. 전체 구조

| 시트 | 화면 역할 | 한 줄 |
|------|-----------|------|
| 달력 | Monthly Planner | 연/월/시작일 조작 → 월간 그리드에 할일 투영 |
| 할일 | Planner 대시보드 | **입력 + 필터 + 요약 차트 + 보조 위젯**이 한 시트 |
| 만다라트 | Mandala Goal Chart | 9×9 목표 분해 (할일과 비연동) |
| 세팅 | 구분 세팅 | 구분 ↔ 이모지 아이콘 마스터 |
| 피벗(숨김) | 엔진 | 월·시작일·통계용 피벗/슬라이서 백엔드 |
| 설명서 | 안내 | 제품 링크 (앱 기능 아님) |

데이터 흐름:

```
세팅(구분·아이콘)
       │
       ▼
할일표 입력 ──► 파생(표시, 상태)
       │
       ├─► 할일 시트: 테이블 · 슬라이서 · KPI · 차트
       └─► 달력 시트: 날짜별 아이콘·우선순위·업무·진행률
만다라트 ─────────► 독립 보드
```

## 1. 달력 (Monthly Planner)

### 1.1 레이아웃 (이미지)

| 영역 | 내용 |
|------|------|
| 상단 좌 | `YYYY년 M월` 현재 선택 표시 |
| 상단 중앙 | 타이틀 **Monthly Planner** + 슬로건 *Plan your month, live your dream* |
| 본문 | 7열 월간 그리드 (주 헤더 + 일자 셀) |
| 우측 패널 | **연도** · **월(1–12)** · **시작일** 컨트롤러 |

### 1.2 우측 컨트롤러 (필수 기능)

1. **연도** — 숫자 + 스피너(증감). 변경 시 그리드·좌측 `N년 M월` 갱신  
2. **월** — 1~12 버튼 그리드. 선택 월 하이라이트(이미지: 연한 파란 테두리/배경)  
3. **시작일** — `일요일` / `월요일` 등. **주 헤더 순서와 첫 칸 정렬이 바뀜**

→ 이전 목업의 «이전/다음 달»만으로는 **기능 부족**. 엑셀은 **연·월 직접 선택 + 주 시작일**이 핵심.

### 1.3 그리드 규칙

- 열: 시작일에 따라 `SUN…SAT` 또는 `MON…SUN`  
- **SUN** 헤더: 주황/브라운 계열 강조  
- **SAT** 헤더: 파란 계열 강조 (이미지)  
- 당월 외 일자: 회색·저대비  
- 일자 숫자는 셀 **상단 중앙**  
- 셀 안 할일 표시(파일 수식 기준, 캡처는 빈 달 예시):
  - 구분 **아이콘** (세팅 매핑)
  - **표시**(우선순위 1/2/3 → 아이콘셋/점)
  - **업무** 제목
  - **진행률**
  - 하루 다건 + overflow 행

### 1.4 숨김 엔진 연동

- 연/월/시작일 선택은 피벗·슬라이서 → `피벗` 시트의 기준일로 전달  
- 달력 첫날 수식: 해당 월 1일·요일·시작일 옵션으로 보정  

### 1.5 앱 구현 시 대응

| Excel | 앱 |
|-------|-----|
| 피벗+슬라이서 연/월 | UI state: `year`, `month` |
| 시작일 슬라이서 | `weekStartsOn: 'sun' \| 'mon'` |
| 배열수식 INDEX/SMALL | `todos.filter(date)` 후 셀 렌더 |

## 2. 할일 (Planner 대시보드)

엑셀 **할일 시트는 단순 테이블이 아니라 한 화면 대시보드**다. (이전 목업·계획에서 과소평가된 부분)

### 2.1 상단 — 필터 · KPI · 차트

| 블록 | 기능 |
|------|------|
| **날짜 슬라이서** | 세로 목록으로 날짜 다중/단일 필터 (이미지: 2026-08-22~24 등) |
| **상태 KPI** | 원형 배지 4개: **전체 / 시작전 / 진행중 / 완료** + 건수 |
| **완료율** | 도넛/링 + 퍼센트 (이미지 30%) |
| **우선순위 차트** | 막대: 높음(적) · 중간(황) · 낮음(녹) + 건수 |
| **구분 슬라이서** | 일정 / 할일 (및 세팅에 있는 구분) |
| **우선순위 슬라이서** | 높음 / 중간 / 낮음 |
| **카테고리 슬라이서** | 데이터에 등장하는 카테고리 (예: 포트폴리오) |
| **상태 슬라이서** | 시작전 / 진행(중) / 완료 |

필터는 테이블·KPI·차트에 **동시에** 적용되는 것이 엑셀 슬라이서 동작.

### 2.2 본문 — 할일표

| 열 | 입력/자동 | UI 특징 (이미지) |
|----|-----------|------------------|
| 구분 | 입력 (세팅 목록) | 일정 / 할일 / 회의 … |
| 날짜 | 입력 | `YYYY-MM-DD` + 요일 |
| 카테고리 | 입력 | 자유 텍스트 |
| 우선순위 | 입력 | 높음/중간/낮음 |
| (표시) | 자동 | 색 점/아이콘셋 (낮음1·중간2·높음3) |
| 업무 | 입력 | 제목 |
| 진행률 | 입력 0~1 | **셀 안 파란 막대 + %** |
| 비고 | 입력 | 메모 |
| 상태 | 자동 | 진행률→시작전/진행중/완료 (표·KPI에 사용) |

파생 규칙 (파일과 동일):

- `표시 = MATCH(우선순위, {낮음,중간,높음})` → 1/2/3  
- `상태 = 진행률==1 → 완료; ==0 → 시작전; else 진행중`  
  (빈 진행률은 시작전으로 보는 샘플 행 존재)

### 2.3 우측 보조 영역

| 위젯 | 기능 | 앱 이식 |
|------|------|---------|
| **Note** | 짧은 메모. 「표시 열 수식 삭제 금지」 안내 | 단순 메모 필드. 엑셀 수식 경고는 웹에서 불필요 |
| **Check List** | 행=루틴명, 열=월~일, 체크(✓) | 요일×루틴 매트릭스 (할일과 별도 로컬 상태) |
| 사용법 패널 3개 | 새로고침·행추가·단축키·붙여넣기 주의 | **엑셀 전용** → 웹에서는 생략하거나 「앱 도움말」로 축소 |

### 2.4 앱 구현 시 대응

- 할일 페이지 = **테이블만이 아니라** 상단 대시보드+필터를 포함해야 엑셀 패리티에 가깝다  
- 차트는 피벗 `GETPIVOTDATA` 대신 **필터된 목록 집계**  
- 진행률은 숫자 입력이되 **바 UI로 표시**

## 3. 만다라트 (Mandala Goal Chart)

### 3.1 레이아웃

- 좌: 타이틀 **Mandala Goal Chart** + 슬로건 박스 + 장식  
- 우: **9×9** 격자 = 중앙 3×3 + 주변 8개의 3×3

### 3.2 셀 역할

| 위치 | 라벨 | 역할 |
|------|------|------|
| 정중앙 (5,5) | 핵심 목표 | 최상위 목표 1개 |
| 중앙 블록 나머지 8칸 | 세부 목표 | 핵심을 쪼갠 8개 |
| 각 외곽 블록의 중앙 | 세부 목표 (미러) | 중앙 블록의 대응 세부 목표와 **동일 내용** |
| 외곽 블록의 나머지 8칸 | 실행 방안 | 해당 세부 목표의 실행 항목 |

### 3.3 동기화 규칙 (핵심 로직)

중앙 3×3의 각 **세부 목표** ↔ 대응 외곽 3×3의 **중앙 칸**은 같은 값.  
한쪽 수정 시 다른 쪽 반영 (엑셀은 수식/복제, 앱은 단일 소스 8칸 + 뷰 미러링).

색: 블록별 파스텔 구분, 핵심만 진한 블루 등.

### 3.4 할일과의 관계

**데이터 비연동.** 목표 보드 전용.  
이전 계획의 P2 취급은 “출시 우선순위” 이야기일 뿐, **제품 기능으로는 1급 시트**.

## 4. 세팅 (구분 · 아이콘)

### 4.1 안내 문구

- 달력 아이콘 변경 시 여기 추가/수정  
- (할일 시트 구분 세팅)  
- 아이콘: 셀 더블클릭 후 Win+V 이모지 (엑셀 UX)

### 4.2 표

| 구분 | 아이콘 (이미지 예시) |
|------|----------------------|
| 일정 | 🗓️ |
| 할일 | ✔️ |
| 회의 | 🎬 |

- 행 추가·수정·삭제 가능해야 함  
- 할일 시트의 **구분 드롭다운 소스**  
- 달력 셀 **아이콘 조회 키**

웹: 이모지 텍스트 입력(또는 피커). Win+V 안내는 플랫폼별 도움말로 대체.

## 6. 기능 우선순위 재제안 (기획용)

### P0 — 핵심 루프

1. 세팅: 구분·아이콘 CRUD  
2. 할일: 표 CRUD + 파생(표시·상태) + 진행률 바 표시  
3. 달력: 연/월/시작일 조작 + 날짜별 투영(아이콘·점·제목·진행)

### P1 — 할일 대시보드 패리티

4. 슬라이서(날짜·구분·우선순위·카테고리·상태)  
5. KPI 원형 4종 + 완료율 링 + 우선순위 막대  
6. Note + Check List  

### P1/P2 — 만다라트

7. 9×9 보드 + 세부 목표 미러 동기화  

### 비이식 (웹에서 제외·축소)

- Ctrl+Alt+F5, Ctrl+X 금지 등 **엑셀 전용** 안내  
- 피벗 시트 UI 자체  
- RAND 장식

## 7. 화면(IA) 권장

분리 페이지 유지 시 엑셀 시트와 1:1:

| 라우트 | 대응 |
|--------|------|
| `/` 또는 `/calendar` | 달력 + 우측 연/월/시작일 |
| `/todos` | 할일 대시보드 전체(상단 KPI·필터 포함) |
| `/mandalart` | 만다라트 (네비에 포함 권장) |
| `/settings` | 구분·아이콘 |

목업도 위 구조에 맞춰 **달력 우측 패널 · 할일 상단 대시보드 · 만다라트 페이지**를 보강하는 것이 다음 작업이다.
