## 1. 왜 만들었는가 (문제 정의)

항상 바쁘지만 ‘뭔가 놓치고 있다’는 불안, 머릿속이 할 일로 가득 찬 상태, 눈앞 업무만 처리하다 방향성을 잃는 하루.

데이비드 앨런 《쏟아지는 일 완벽하게 해내는 법》(GTD):

> 머릿속에만 들어 있는 ‘할 일, 할 수 있는 일, 혹은 해야 하는 일’은 매일매일 하루 24시간 내내 비합리적이고 해결도 안 되는 압박을 가할 것이다.

- 뇌는 **기억 저장소가 아니라 창조 엔진**이어야 한다.
- 노트·엑셀에 할 일을 적어도 불안이 남는 이유: **『오늘의 작은 행동』과 『인생의 큰 그림』 사이 연결고리가 안 보이기 때문**.

**시크릿 브레인**은 그 연결을 만들어 막연한 불안을 줄이고 목표 달성을 돕기 위해 설계되었다.

## 2. 시스템 구성 (6단계 두뇌 정리)

단순 To do list가 아니라, 아래 여섯 요소가 톱니처럼 맞물리는 **성장·자신감 시스템**이다.

| 단계 | 요소 | 역할 |
|------|------|------|
| 1 | **만다라트** | 인생의 큰 그림·장기 목표·가치 설계 |
| 2 | **프로젝트** | 구체적 목표가 있는 프로젝트·하위 업무로 구조화 |
| 3 | **할일** | 오늘 당장 실행할 행동으로 전환 |
| 4 | **주간 회고** | 실행 점검·개선점 |
| 5 | **질문 카드** | 시야·가치관·방향성 점검 |
| 6 | **능력치** | 사용 전후 성장 체감·자신감 |

연결 고리:

```
장기 목표 ↔ 프로젝트 ↔ 하위 업무 ↔ 오늘 할일
```

철학 요약: 복잡한 기억은 도구에 맡기고, **다음 할 일만 기억·실행**하며, 남는 에너지를 창의에 쓴다.

## 3. 사용자가 얻게 될 변화 (기대 효과)

- 회사 프로젝트·할일을 체계적으로 정리
- 정신없던 하루가 명확해짐
- 불가능해 보였던 목표 달성 가능성
- 업무를 넘어 인생을 주도적으로 정리
- 오늘의 행동 ↔ 장기 목표 연결 → 불안 감소
- 실행 축적 → 방향성·자신감
- 체크리스트를 넘어 삶 설계
- 성장을 눈으로 확인 → 자기 확신
- 집중력·생산성 향상, 기록이 자산으로 남음

## 6. 할일 시트

### 6.1 설계 의도

- 업무 입력 → **주간 달력·월간 달력(달력 시트)에 자동 반영**
- 시트 이동 없이 주간 흐름을 짜기 쉽게
- 검색 시트로 과거 기록을 빠르게 확인 → 완벽 정리에 집착하지 않아도 됨
- 연동: 달력, 검색, 대시보드, 세팅

### 6.2 구분 (일정 vs 할일)

| 구분 | 예시 | 설명 |
|------|------|------|
| 일정 | 10:00 팀 회의, 고객 미팅 | 시간·장소가 고정된 약속. **시간이 중요** |
| 할일 | 보고서 작성, 데이터 입력 | 기간 내 완료 작업. **완료 여부·진척도가 중요** |

- 자주 안 바뀌는 구분 → **세팅 시트에 등록** 후 선택
- 수시로 바뀌는 분류 → **카테고리 열에 직접 입력**

### 6.3 구분 아이콘

- 세팅 시트에서 추가·수정
- 이모지: 셀 더블클릭 후 Win+V 등 (엑셀 UX)

### 6.4 입력·표 동작 (엑셀)

- 표 아래 입력 시 범위 자동 확장
- 채우기: `Ctrl+Shift+↑` → `Ctrl+D`
- 오늘 날짜: `Ctrl+;`
- 행 추가/삭제·순서 변경: 원문 단축키 참고
- **표시 열**: 내부 수식 → **삭제 금지**

### 6.5 주요 입력 항목

| 항목 | 의미 |
|------|------|
| 카테고리 | 프로젝트/하위 업무명, 또는 회사·집 등 자유 분류 |
| 우선순위 | 높음 / 중간 / 낮음 |
| 업무 | 구체적 실행 항목 |
| 진행률 | 0~100 숫자 |

**상태 파생 (원문 기준, %):**

| 상태 | 조건 |
|------|------|
| 시작전 | 진행률 미입력 |
| 진행중 | 0~99% |
| 완료 | 100% |

> 코드 구현 시: 현재 보유 엑셀 2.2 샘플은 0~1 소수 진행률·상태 수식도 있음. **제품 규칙을 하나로 통일**할 때 원문(0~100) vs 파일(0~1)을 맞춰야 함.

### 6.6 대시보드

- 입력 후 **데이터 새로고침**으로 반영 (엑셀: `Ctrl+Alt+F5`)
- 웹 구현 시: 저장 즉시 반영하면 새로고침 UX는 불필요

### 6.7 슬라이서·필터

| 위치 | 역할 |
|------|------|
| 날짜 슬라이서 | 대시보드 KPI·우선순위 완료 현황 연동. 오늘만 보기, 복수 선택 |
| 왼쪽 (주간 달력용) | 연도·월·주차, 시작 요일(일/월) |
| 오른쪽 (할일표) | 구분 / 우선순위 / 카테고리 / 상태 |

팁: Ctrl 다중 선택, 「완료」만 끄기, 필터 해제로 전체 복구

### 6.8 메모지 · 미니 체크리스트

- **메모지:** 메모·다짐·명언. (팁: 주간회고와 `=` 연동 가능 — 엑셀)
- **미니 체크리스트:** 매일 반복 루틴. 1 또는 드롭다운 체크. 주 단위로 지우고 재사용

### 6.9 Tip (반복 일정 → 달력)

월요일 반복을 달력에 넣으려면 날짜에 `+7` 채우기 후 **값 붙여넣기**하고 오름차순 (수식 상태 정렬 금지)

## 7. 달력 시트

### 7.1 설계 의도

- 월간 일정·할일 **한눈에**
- 할일 시트 자동 반영
- **만년형:** 연·월·시작 요일 자유 설정
- 카테고리 등 필터로 필요한 것만
- 시트 보호(암호 없음)로 수식 삭제 방지 — 웹에서는 편집 권한 설계로 대체

### 7.2 기능

| 기능 | 설명 |
|------|------|
| 자동 연동 | 할일 → 달력 표시 |
| 연도 변경 | 화살표/스피너 |
| 월 변경 | 월 슬라이서(1~12) |
| 시작 요일 | 일요일 / 월요일 |
| 필터 | 구분·카테고리·상태·우선순위 |
| 크기 | 기본 하루 **8개**, 확장 **16개**. 초과 시 노랑/주황 표시등 |
| 장식 | 크리스마스 트리(감성). F9/슬라이서 시 점등 — 웹 구현 시 선택 |

## 8. 검색 시트

- 할일 시트와 연동, 검색창 + Enter → **1초 검색**
- 검색 대상: 구분, 날짜, 카테고리, 우선순위, 업무, 비고, 상태  
  (날짜: `2026`, `2026-01`, `2026-01-05` 등)
- 할일에 새 열 추가 시 검색에도 반영
- 엑셀 구버전 1000행 제한 이슈는 웹 DB/인덱스에서는 해당 없음

## 9. 프로젝트 시트

### 9.1 설계 의도

피터 드러커: 숲과 나무를 함께 보고 연결하라.

체크리스트만으로는 전체 흐름·우선순위가 흐려질 때 사용.

```
만다라트(어떻게 살고 싶은지)
  → 프로젝트(구체 목표)
    → 하위 업무
      → 할일 시트(오늘 실행)
```

**중요:** 프로젝트에 입력해도 **할일에 자동 입력되지 않음**.  
두 시트는 **의도적으로 분리** — 완전 연동은 자유도를 해친다고 판단.

간트: 과도한 기능·색은 느려짐 → **속도·실용성** 우선. Day/Week, 필터, 1년 흐름.

### 9.2 기록

- **프로젝트:** 시작일·마감일 있고 2단계 이상인 큰 단위
- `*` 열로 프로젝트 지정, 하단에 하위 업무, `>` / `>>`로 깊이
- 항목: `*`, 진행사항, 담당자, 우선순위(1높음/2중간/3낮음), 시작일, 마감일, 진행률

### 9.3 간트차트

- 진행률 시각화, 오늘 기준선 대비 앞서감/지연
- Day / Week 전환, 시작일 변경, 스크롤 이동

### 9.4 D-day 대시보드 (핵심 UX)

완료되지 않은 업무 중 D-day **-7~7**만 표시. 진행률 100이면 사라짐.

| 유형 | 의미 | 색 감각 |
|------|------|---------|
| 기한 초과 | 마감 지남(7일 이내) | 빨강 → 바로 처리 |
| 오늘 마감 | 마감=오늘 | 파랑 → 지금 |
| 포함 | 오늘이 시작~마감 사이 | 파랑 → 지금 |
| 마감 임박 | 7일 이내 | (검정 등) → 조만간 |

**목표:** 기한초과(빨강)·오늘/포함(파랑) 건수를 **0**에 가깝게.

### 9.5 기타

- 행 추가/삭제는 **행 전체**(간트 포함) 선택 필수 — 엑셀 제약
- ID, D-day, 일수, 상태 수식 삭제 금지
- 상태: 진행률 0=시작전, 1~99=진행중, 100=완료
- 날짜를 `=시작일+3`처럼 상대 연동하면 일정 밀림 시 일괄 조정 가능

## 10. 주간 회고

한 주의 목표·실행을 정리해 **계획과 실행의 간극**을 보는 지도.  
성찰 → 성장 촉매.

사용:

1. 목표와 실행 정리  
2. 평점 1~5  
3. 회고 최소 한 줄씩: **감사 / 칭찬 / 반성**

## 11. 만다라트

큰 그림 속에서 지금 무엇을 하는지 알게 하는 도구.

- 핵심 목표 → **8** 세부 목표 → 각 8 실행 = **64** 실행 아이디어
- 결과를 **프로젝트·할일**로 옮겨 연결
- 브레인스토밍·계획 구조화에도 사용
- Tip: 채워가는 조각은 글자색으로 강조

## 12. 능력치

일을 끝내는 것을 넘어 **성장 체감**.

1. 측정 항목 입력 (업무 지식, 리더십 등)  
2. 목표치  
3. 시작 값  
4. 주기적으로 현재 값 갱신  

시작 → 현재 → 목표를 한눈에.

---

## 13. 질문카드

실행만이 아니라 **성찰**.  
영역: 자아 성찰, 마음 건강, 인간관계, 부, 생산성.

사용: 질문 선택 → (캡처·휴대) → 답변 메모 → **만다라트에 반영**.

참고 서적 목록은 원문 Notion 참고 (GTD, 세컨드브레인, 원씽, 습관의 힘 등).

---

## 14. 주의사항 요약 (엑셀 운영)

웹 이식 시 대부분은 **해당 없음**이나, 데이터 무결성 관점에서 대응 개념만 남김.

- 사본 보관 (엑셀)
- 수식 열 삭제 금지: 할일(표시·상태·필터), 프로젝트(ID·D-day·일수·상태), 주간회고(별표)
- 잘라내기 금지 → 조건부 서식 붕괴
- 값 붙여넣기 권장 (`Ctrl+Shift+V` 등)
- 프로젝트 행 조작은 전체 행
- 대시보드 반영 = 새로고침 (엑셀)

## 15. 코드 구현을 위한 기획 의도 요약

원 저자의 제품 한 줄:

> **장기 목표(만다라트) → 프로젝트 → 하위 업무 → 오늘 할일**을 잇고,  
> **회고·질문·능력치**로 성장 루프를 닫는 올인원 시스템.

현재 레포의 `To_do_list_2.2.xlsx` / 목업은 그중 **할일·달력·세팅·만다라트** 축에 가깝고,  
검색·프로젝트(간트·D-day)·주간회고·능력치·질문카드는 **확장 로드맵**으로 보면 된다.

구현 우선 제안 (기획 의도 정렬):
