# MVP Scope · DeskList

**원칙:** 목업(`mockups/`)에 **이미 동작하는 기능만** P0. Excel 전체·피벗 UI·배포는 제외.  
**성공 기준:** 할일 입력 → 달력(및 필터/KPI) 반영.

기준 코드: `mockups/js/store.js` + `calendar` / `todos` / `mandalart` / `settings` 페이지.

---

## In (P0)

### 공통
- 4화면 IA: 달력 · 할일 · 만다라트 · 설정 + 상단 네비
- 단일 할일 스토어(소스 오브 트루스) · 달력/KPI는 파생
- 로컬 영속(목업: localStorage) · 샘플 seed / 초기화

### 할일 모델
- 입력: 구분, 날짜, 카테고리, 우선순위, 업무(제목), 진행률(0–100), 비고
- 파생: 표시(1/2/3), 상태(시작전/진행중/완료)
- CRUD · 행 선택 편집 · 구분 마스터와 연동

### 달력
- 월간 그리드 · 연/월 · 주 시작(일/월)
- 밀도 8/16 · 칸: 아이콘·표시·제목·진행 바 · 완료 스타일
- overflow 텍스트(`+N 더보기`) · >8 / >16 경고 표시
- 필터: 구분·카테고리·상태·우선순위 · 필터 해제
- 날짜 클릭 → 할일 화면 날짜 딥링크

### 할일 화면
- 주간 패널(연/월/주차/시작일) · 날짜 필터 연동
- 슬라이서(구분·우선순위·상태·카테고리)
- KPI: 건수·완료율·우선순위 스택
- 표 + 사이드 에디터

### 만다라트
- 9×9(81칸) 편집 · 자동저장
- 세부↔외곽 미러
- 선택 칸 → 할일로 보내기(목업과 동일 동작)

### 설정
- 구분 ↔ 아이콘 CRUD(최소 1개) · 이름 변경 cascade
- 샘플 초기화

### 디자인
- E(본문) + B(네비) — `DESIGN.md` / `tokens.css`

---

## Out (비범위)

- Excel 피벗·슬라이서 UI 복제, GETPIVOTDATA 시트
- 배포·호스팅·인증·다기기 동기화·백엔드 DB
- 설명서 시트, 시트 보호/비밀번호, RAND 장식
- 반복/루틴 할일, 알림, DnD로 일정 이동
- Note / Check List 위젯 (현 목업 미구현)
- 파일 import/export, Excel 0–1 진행률 스케일
- 만다라트↔할일 양방향·목표 진행 연동(일방향 보내기 이상)
- 디자인 샘플 보드(`design-variants` 등)는 제품 기능 아님

## 목업 한계 → MVP 처리

| 항목 | 목업 상태 | MVP |
|------|-----------|-----|
| `+N 더보기` | 표시만 | 동일(펼침 없음) |
| 달력/주간 `weekStartsOn` | 서로 미동기 | **동기화** (작은 수정, 범위 안) |
| 만다라트→할일 날짜 | 하드코딩 | **선택일 또는 오늘**으로 교정 |
| `#date-slicer` | 데드 | 구현하지 않음 |
| 표에 비고 컬럼 | 없음(폼만) | 동일 |
| 에디터→달력 링크 | 주석 | 선택(P1) |
